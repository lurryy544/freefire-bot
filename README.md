# 💎 Free Fire Diamond Bot

Telegram-бот для продажи алмазов Free Fire. Клиент выбирает пакет, вводит игровой
ID, видит реквизиты оплаты, отправляет скриншот — а вы получаете уведомление
с ID и скриншотом.

Стек: Node.js + [grammY](https://grammy.dev). Хранилище — файл `data/db.json`
(без внешних БД). Long polling — публичный сервер не нужен.

## Как это работает

1. Клиент нажимает `/start` и видит прайс с пакетами (кнопки).
2. Выбирает пакет — бот просит ввести игровой ID.
3. Клиент вводит ID — бот показывает реквизиты карты и сумму.
4. Клиент нажимает «Я оплатил(а)» и отправляет скриншот.
5. Бот отвечает, что алмазы скоро придут, и пересылает вам (админу)
   скриншот + сведения о заказе.

История заказов сохраняется в `data/db.json`.

## Быстрый старт

1. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Узнайте свой Telegram id через [@userinfobot](https://t.me/userinfobot).
3. Установите [Node.js](https://nodejs.org) (18+).
4. Установите зависимости и настройте:
   ```
   npm install
   copy .env.example .env
   ```
5. Откройте `.env` и заполните:
   - `BOT_TOKEN` — токен от BotFather;
   - `BOT_OWNER_ID` — ваш Telegram id (можно несколько через запятую), сюда
     приходят заказы;
   - `PAYMENT_CARD` — номер карты;
   - `CARD_HOLDER` — имя получателя;
   - `ADMIN_COMMENT` — необязательная подпись (например «Логин поддержки: ...»).
6. Запуск:
   ```
   npm start
   ```
   Бот включён, пока открыт этот терминал. Для работы 24/7 используйте VPS
   (например `npx pm2 start src/bot.js --name freefire-bot`).

## Прайс-лист

Цены заданы в `src/catalog.js` (массив `packages`): меняйте `gems` и `price`,
и бот сам обновит кнопки.

## Запуск вручную заново

```
npm start
```

## Деплой на Render (бесплатно, 24/7)

1. Загрузите этот репозиторий на GitHub (Private или Public).
2. Зайдите на https://render.com и зарегистрируйтесь (можно через GitHub).
3. Нажмите **New + → Web Service** и подключите GitHub.
4. Выберите этот репозиторий. Render сам определит Node.js:
   - Build Command: `npm ci`
   - Start Command: `npm start`
5. В разделе **Environment** добавьте:
   - `BOT_TOKEN` — токен от BotFather;
   - `BOT_OWNER_ID` — ваш Telegram id (без `@`, цифрами; можно несколько через запятую);
   - `PAYMENT_CARD` — номер карты;
   - `CARD_HOLDER` — имя получателя;
   - `ADMIN_COMMENT` — подпись к карте (необязательно).
   Прокси не нужен.
6. Нажмите **Deploy Web Service**. Через 2–4 минуты бот онлайн.
7. Бесплатные инстансы Render засыпают без входящего трафика. Чтобы бот работал
   без перерывов, зарегистрируйтесь на https://uptimerobot.com и создайте монитор
   (HTTPS, интервал 5 минут) на адрес вида `https://ВАШ-СЕРВИС.onrender.com`.

Заказы сохраняются в файл `data/db.json`; на бесплатном инстансе диск временный —
история пропадает при перезапуске. Для важного хранения подключите платный диск
или внешнюю БД.

## Безопасность

- `.env` содержит токен бота — не публикуйте его (файл уже в `.gitignore`).
- Реквизиты карты в открытом виде в базе не хранятся, только в `.env`.
